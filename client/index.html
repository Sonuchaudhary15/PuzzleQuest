SOFTWARE FOR ENTERPRISE ARCHITECTURE

Mapping of the four core university themes to actual codebase modules.

1. Version Control

Structured Git repository with clean separation of concerns, .gitignore safeguarding environment secrets and node_modules, feature branching strategy, comprehensive test suite, and atomic commits.

2. Interoperability

Demonstrated via standard HTTP/JSON REST APIs between frontend and Express.js, MongoDB database persistence, and secure backend proxy integration with the external University of Bedfordshire Banana API.

3. Event-Driven Programming

Centralized EventBus implements the Publish/Subscribe pattern. Fully decouples core match physics (MainBoard), connected Echo Board, particle effects (BoardRenderer), Web Audio synthesizer (SoundManager), and UI HUD counters.

4. Virtual Identity

End-to-end player identity management with salted bcrypt password hashing, JSON Web Tokens (JWT) for stateless authorization, user profile statistics, persistent inventories, and verified online leaderboard scores.
